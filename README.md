# Al-Omran Industrial Theme

Professional WordPress theme for manufacturing and industrial companies specializing in stainless steel drainage systems, grease traps, and water treatment solutions.

## Features

- **Product Showcase**: Custom post type for products with categories
- **News/Blog**: News posts for company updates
- **Testimonials**: Customer testimonials management
- **FAQ**: Frequently asked questions
- **Statistics Section**: Display company statistics
- **Redux Framework**: Comprehensive theme options panel
- **Demo Import**: One-click demo content import
- **RTL Support**: Full Arabic/RTL support
- **SEO Optimized**: Built-in SEO features

## Installation

1. Upload the theme to `wp-content/themes/`
2. Activate the theme from WordPress admin
3. Install required plugins:
   - Redux Framework
4. Import demo content from Theme Settings → Setup Wizard

## Requirements

- WordPress 5.0+
- PHP 7.4+
- Redux Framework Plugin
