# Al-Omran Tech Theme

Modern WordPress theme for SaaS platforms, technology companies, APIs, and automation services.

## Features

- **Hero Section**: Eye-catching hero with CTA buttons
- **Features Showcase**: Tabbed interface displaying different feature categories
- **Pricing Plans**: Flexible pricing with monthly/annual toggle
- **Use Cases**: Detailed case studies with problem-solution-result format
- **About Page**: Company story with statistics
- **Contact Form**: Integrated contact form with validation
- **Page Loader**: Customizable page loader
- **Redux Framework**: Comprehensive theme options panel
- **Demo Import**: One-click demo content import
- **RTL Support**: Full Arabic/RTL support
- **SEO Optimized**: Built-in SEO features

## Installation

1. Upload the theme to `wp-content/themes/`
2. Activate the theme from WordPress admin
3. Install required plugins:
   - Redux Framework
4. Import demo content from Theme Settings → Setup Wizard

## Requirements

- WordPress 5.0+
- PHP 7.4+
- Redux Framework Plugin

## Custom Post Types

- None (uses WordPress pages only)
