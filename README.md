# Al-Omran Food Theme

Modern WordPress theme for restaurants, cafes, and food businesses with reservation system and menu management.

## Features

- **Menu Management**: Custom post type for menu items with categories
- **Reservation System**: Built-in reservation management
- **Blog/News**: Blog posts for restaurant news and updates
- **Branches**: Multi-location support with branch management
- **ACF Integration**: Advanced custom fields for menu items and branches
- **Redux Framework**: Comprehensive theme options panel
- **Demo Import**: One-click demo content import
- **RTL Support**: Full Arabic/RTL support
- **SEO Optimized**: Built-in SEO features

## Installation

1. Upload the theme to `wp-content/themes/`
2. Activate the theme from WordPress admin
3. Install required plugins:
   - Redux Framework
   - Advanced Custom Fields (ACF)
4. Import demo content from Theme Settings → Setup Wizard

## Requirements

- WordPress 5.0+
- PHP 7.4+
- Redux Framework Plugin
- Advanced Custom Fields (ACF) Plugin

## Custom Post Types

- `menu_item` - Menu items with categories
- `blog_post` - Blog posts
- `branch` - Restaurant branches
- `reservation` - Reservations (admin only)

## Taxonomies

- `menu_category` - Menu item categories

## Page Templates

- `front-page.php` - Homepage
- `page-branches.php` - Branches listing
- `page-contact.php` - Contact page
- `page-experience.php` - Experience page
- `page-reservations.php` - Reservations page
- `page-story.php` - Story page
