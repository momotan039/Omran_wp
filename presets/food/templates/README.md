# Food Preset Templates

This directory contains WordPress template files for the Food preset.

## Template Hierarchy

Templates in this directory override core theme templates when the Food preset is active.

## Available Templates

- `archive.php` - Archive page template
- `single.php` - Single post template
- `page-*.php` - Page-specific templates
- `single-product.php` - Single product template
- `single-news.php` - Single news template

## Usage

Templates are automatically loaded by the preset loader system. No manual inclusion needed.
