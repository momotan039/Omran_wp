# Common Template Parts

Common reusable template parts for the Food preset.

## Files

- `archive-header.php` - Archive page header
- `archive-loop.php` - Archive loop template
- `page-header.php` - Page header
- `page-content.php` - Page content wrapper
- `single-header.php` - Single post header
- `single-content.php` - Single post content
- `helpers.php` - Helper functions
- `section-loader.php` - Section loader
