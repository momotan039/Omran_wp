# Header Template Parts

Header variations for the Food preset.

## Available Headers

- `header-default.php` - Default header with navigation
- `header-centered.php` - Centered header layout
- `header-minimal.php` - Minimal header style
- `header-transparent.php` - Transparent header
- `header-logo.php` - Logo component
- `header-nav.php` - Navigation component
- `header-mobile-menu.php` - Mobile menu component
- `header-loader.php` - Page loader component
