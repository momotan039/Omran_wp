# Tech Preset

Modern SaaS platform preset for technology companies, APIs, and automation services.

## Overview

The Tech preset is designed for Arabic SaaS platforms, featuring a modern, clean design optimized for technology companies offering API integrations, automation services, and fintech solutions.

## Features

- **Hero Section**: Eye-catching hero with CTA buttons and dashboard preview
- **Features Showcase**: Tabbed interface displaying different feature categories
- **Pricing Plans**: Flexible pricing with monthly/annual toggle
- **Use Cases**: Detailed case studies with problem-solution-result format
- **About Page**: Company story with statistics and location
- **Contact Form**: Integrated contact form with validation

## Page Templates

- `front-page.php` - Homepage with hero and case study sections
- `page-features.php` - Features showcase page
- `page-pricing.php` - Pricing plans page
- `page-use-cases.php` - Use cases page
- `page-about.php` - About page with team and location
- `page-contact.php` - Contact page with form

## Template Parts

### Header
- `header-loader.php` - Loads Tailwind CSS and header template
- `header-default.php` - Default header with logo, navigation, and mobile menu

### Footer
- `footer-default.php` - Footer with links, social media, and copyright

### Sections
- `section-hero.php` - Hero section with badge, title, description, and CTA buttons
- `section-case-study.php` - Case study section with image and link

## Redux Configuration

The preset includes comprehensive Redux Framework integration:

### Homepage Sections
- Hero section settings
- Features section settings
- Case study section settings

### Page Settings
- Features page configuration
- Pricing page configuration
- Use cases page configuration
- About page configuration
- Contact page configuration

### General Settings
- Header settings (logo, navigation)
- Footer settings (description, copyright)
- Social media links
- Typography settings
- Color settings

## Demo Data

The preset includes demo data for:
- Pages (Features, Pricing, Use Cases, About, Contact)
- Menus (Primary and Footer menus)
- Redux settings (pre-configured values)

## Assets

- `assets/css/preset.css` - Preset-specific styles
- `assets/js/preset.js` - Preset-specific JavaScript

## Installation

1. Ensure the Tech preset is selected in Redux Framework settings
2. Import demo data from the demo import interface
3. Configure Redux settings as needed
4. Customize content and images

## Color Scheme

- Primary: `#2563eb` (Blue)
- Secondary: `#1e293b` (Slate)
- Accent: `#6366f1` (Violet)

- Font Family: Cairo
- Font Weight: 400 (regular) to 900 (black)
