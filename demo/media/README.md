## Image Specifications

- **Format**: JPG or PNG
- **Recommended Size**: 
  - Product images: 800x600px
  - News images: 1200x675px
  - Hero images: 1920x1080px
  - Logo: 300x150px (transparent PNG preferred)

## Notes

- All images should be optimized for web
- Use Arabic/RTL-friendly placeholder images
- Images will be automatically imported to WordPress Media Library during demo import
- If images are not available, the system will work without them but featured images won't be set
